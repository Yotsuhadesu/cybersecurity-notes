## Linux Fundamentals Part 1
- Linux is a lightweight operating system
- Released in 1991
- Commands: `echo`, `cd`, `ls`, `find`, `grep`, `>`, `>>`, `&`, `&&`
- Key takeaways: `find` and `grep` are powerful commands that locates files or texts

- Actions:

  - HTTP Query
